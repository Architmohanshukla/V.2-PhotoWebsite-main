DEPLOYMENT STEPS:
─────────────────────────────────────────────────────────────────────────────

Step 1: STAGE CHANGES
  Run: git add .
  └─ Adds all modified and new files

Step 2: COMMIT CHANGES
  Run: git commit -m "Portfolio upscale: Add image optimization and upload system"
  └─ Creates a commit with descriptive message
  └─ Or use custom message like:
     - "Portfolio v2.1: 3x faster + drag-drop uploads"
     - "Optimize images + add admin dashboard"

Step 3: PUSH TO GITHUB
  Run: git push origin main
  └─ Pushes to your main branch
  └─ If different branch, use: git push origin <branch-name>

Step 4: MONITOR DEPLOYMENT
  1. Visit your Netlify dashboard
  2. Watch for "Building..." status
  3. Wait for "Published" status (~30 seconds)
  4. Check "Deploy log" if there are any issues

TROUBLESHOOTING DURING DEPLOYMENT:
─────────────────────────────────────────────────────────────────────────────

"Build failed" error?
→ Check Netlify deploy logs
→ Verify all files exist
→ Ensure no syntax errors in JS/CSS

"404 on some pages"?
→ Check netlify.toml redirects
→ Verify file paths
→ Clear browser cache

"Images not loading"?
→ Check file paths (use forward slashes for web)
→ Verify image folders exist
→ Check image permissions

"Modal not showing"?
→ Hard refresh browser (Ctrl+Shift+R)
→ Clear cache (Ctrl+Shift+Delete)
→ Check console for errors

"Slow performance"?
→ Check Core Web Vitals in Lighthouse
→ Verify lazy loading is working
→ Compress large images

ROLLBACK PLAN (If Needed):
─────────────────────────────────────────────────────────────────────────────

If something goes wrong, revert with:

  git revert HEAD
  git push origin main

This will undo the last commit.

Or restore a specific version:

  git log --oneline
  git reset --hard <commit-hash>
  git push origin main -f
