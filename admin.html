📚 How to Upload Images

  1. Go back to the Portfolio page
  2. Click the "+ Upload Photos" button in the gallery
  3. Drag & drop your images OR click to select
  4. Choose a category (or auto-detect from filename)
  5. Click "Upload Photos"
  6. Follow the instructions to complete the upload

⚙️ Alternative: GitHub Upload

  1. Visit your GitHub repository
  2. Navigate to uploaded-images/
  3. Create a folder for the category if needed: nature, landscape, etc.
  4. Click "Add file" → "Upload files"
  5. Select your images and commit
  6. Netlify auto-deploys in ~30 seconds
