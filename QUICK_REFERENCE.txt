## Image Naming Tips

**Auto-detected categories:**
- `nature_*.jpg` → Nature
- `landscape_*.jpg` or `ls_*.jpg` → Landscape
- `portrait_*.jpg` → Portrait
- `abstract_*.jpg` or `abs_*.jpg` → Abstract
- `arch_*.jpg` or `architecture_*.jpg` → Architecture

**Example:**
```
✅ Good: nature_sunset.jpg → Goes to nature folder
✅ Good: ls_mountains.jpg → Goes to landscape folder
❌ Bad:  photo.jpg → Goes to misc (can't auto-detect)
```

## Common Issues & Fixes

| Problem | Fix |
|---------|-----|
| Modal not showing | Hard refresh: `Ctrl+Shift+R` |
| Admin not loading | Clear cache + refresh |
| Images not lazy loading | Check `loading="lazy"` attribute in HTML |
| Slow performance | Images are too large - compress them |
| Upload not working | Check browser console (F12) for errors |
